## 六、推送与 PR

1. 本地验证：`./manage.sh update` + 容器内代码指纹 grep（已验证通过）
2. 依次 commit，`git push origin develop`
3. 手动创建 PR（develop → main）：标题 `release: v3.21.1 通知系统与系统配置保存不生效修复`
4. 复核 CI 后 Merge（Merge commit，不 squash）

## 七、打 tag 与 develop 同步

```bash
git checkout main && git pull origin main
git tag -a v3.21.1 -m "release v3.21.1: 通知模板/事件订阅/系统配置保存不生效修复"
git push origin v3.21.1
git checkout develop && git merge main && git push origin develop
```
