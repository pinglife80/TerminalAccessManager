## 四、代码提交计划

### 提交 1：通知系统修复

```
fix(notification): restore notification pipeline and fix event type strings

- Remove aggregator bypass in emit_event(), route events directly to
  NotificationService.emit() → Redis Queue → Worker pipeline
- Fix 3 event type string mismatches: system.system_error → system.error
  (same for warning and alert)
- Add REALTIME_EVENT_TYPES set for real-time event classification
- Add event coverage monitoring to get_statistics() API
- Add emit_auto_block_triggered call in compliance_service
- Implement terminal offline detection in arp_collector_service
```

涉及文件：

* event\_emitter.py

* notification\_channels/event\_types.py

* notification\_workers.py

* notification\_service.py

* compliance\_service.py

* arp\_collector\_service.py

### 提交 2：定时备份修复

```
fix(backup): implement cron schedule parser and fix FTP timestamp/path issues

- Rewrite scheduled_backup() to parse cron expression from backup_config.schedule
  instead of using fixed interval; poll every 60s and only run when cron matches
- Add _should_run_backup_now() cron matcher (supports *, comma, step values)
- Add Redis-based dedup to prevent duplicate runs within same minute window
- Write scheduled backup results to audit_logs for frontend visibility
- Fix FTP remote backup timestamp: convert UTC MDTM time to local timezone (UTC+8)
- Fix FTP remote path double slash: use remote_path.rstrip('/') before concatenation
- Fix backup list sort TypeError: unify naive/aware datetime comparison
- Add scheduler_backup_interval config field and frontend support
```

涉及文件：

* main.py

* backup\_service.py

* backup.py (endpoint)

* system\_config.py

* config\_service.py

* useTerminalData.ts

* GeneralSettings.tsx

涉及文件：
