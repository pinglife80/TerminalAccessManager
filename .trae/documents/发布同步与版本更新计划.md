### 阶段 5 — 打 tag + 同步

```bash
# 1. 合并后，本地切 main 拉最新

git tag -a v3.14.0 -m "release v3.14.0: blacklist operation tracking + stats caliber unification + reconciliation improvements"
git push origin v3.14.0

# 3. 同步 develop（确保 develop 包含 tag 与最新 main）
git checkout develop
git merge main
git push origin develop
```
