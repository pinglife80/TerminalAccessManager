## 七、打 tag 与 develop 同步

> 依据项目约束「Git tag 仅打于 main、且须 PR 合并后」。

1. PR 合并后，本地同步并切到 main：
   ```bash
   git checkout main && git pull origin main
   ```
2. 打 annotated tag 并推送：
   ```bash
   git tag -a v3.17.0 -m "release v3.17.0: compliance anti-oscillation parameterization"
   git push origin v3.17.0
   ```
3. develop 同步 main（含 tag）：
   ```bash
   git checkout develop && git merge main && git push origin develop
   ```
